# Тестирование сайта dotiza.ru

Данный репозиторий содержит артефакты ручного тестирования веб-приложения [Dotiza](https://dotiza.ru/). 
Тестирование проводилось в формате Black-box.

##  Инструменты, которые использовались:
* **Google Sheets** — для написания и структурирования тест-кейсов.
* **Chrome DevTools** — анализ вкладки Network, проверка валидации.
* **Postman** — тестирование API.
