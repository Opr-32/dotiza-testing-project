# test_cases_dotiza.ru
Тест-кейсы для тестирование сайта dotiza.ru


Данный репозиторий содержит информацию о тестировании сайта https://dotiza.ru/


Инструменты, которые использовались:

Google Sheets (для написания тест-кейсов)
Chrome DevTools (анализ Network, проверка валидации)
Postman (тестирование API)
